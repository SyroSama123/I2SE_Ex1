# I2SE_Ex1 — 3D Volume Plane Projection

A Java application that projects planes defined in 3D space onto a three-dimensional raster volume. The application reads a NRRD volume and plane definitions from a CSV file, generates projection images as PNG files, and can combine the generated images into an MP4 video using FFmpeg.

## Features

- Read 3D volumetric data from NRRD files.
- Parse triangle and quadrilateral plane definitions from CSV files.
- Generate 2D projection images in PNG format.
- Create an MP4 video from the generated projection images.
- Validate input arguments and handle invalid input.
- Build and test using Maven and Java 21.

## Requirements

- Java Development Kit (JDK) 21
- Apache Maven
- FFmpeg, for video generation
- A compatible NRRD input volume
- A CSV file containing plane definitions


Use the actual JAR path and filename generated by Maven. If the current implementation requires the NRRD file as an additional argument, include it in the argument list according to the application's command-line interface.

## Input Format

### NRRD volume

The input volume must be a valid NRRD file supported by the project's NRRD reader.

The volume represents a 3D raster with dimensions:

- `sx`: width
- `sy`: height
- `sz`: depth

Each dimension must satisfy:

```text
0 <= dimension <= 1024
```

Supported voxel data types depend on the NRRD reader implementation and the input file's encoding.

### CSV plane definitions

Each CSV row defines a plane using three or four 3D points.

The expected format is:

```csv
x1,y1,z1,x2,y2,z2,x3,y3,z3,x4,y4,z4
```

- **Triangle:** Supply the first nine coordinate values. The fourth point is omitted.
- **Quadrilateral:** Supply all twelve coordinate values.

Each point is represented by its three coordinates `(x, y, z)`.

Example triangle:

```csv
10,20,30,40,20,30,10,50,30
```

Example quadrilateral:

```csv
10,20,30,40,20,30,40,50,30,10,50,30
```

Coordinates must conform to the geometry and volume-boundary constraints enforced by the implementation.

## Output

### Projection images

The application generates PNG images for the supplied planes. The output directory and naming convention depend on the implementation; the current project convention is:

```text
projection_frames
├── projection_0.png
├── projection_1.png
└── ...
```

### MP4 video

FFmpeg combines the generated PNG images into an MP4 video. The output path is supplied to the application or configured by its implementation.

Ensure that FFmpeg is installed and accessible through your system's `PATH`.

## Troubleshooting

**`java` is not recognized**

Verify that JDK 21 is installed and that its `bin` directory is included in `PATH`.

**`mvn` is not recognized**

Verify that Maven is installed and restart the terminal.

**`ffmpeg` is not recognized**

Verify the FFmpeg installation and ensure its executable is accessible through `PATH`.

**The application cannot read the NRRD file**

Check that the file exists, is a valid NRRD file, and uses an encoding supported by the reader.

**No projection images are generated**

Check the CSV format, coordinate values, and input paths. Review the application output for validation errors.

**Video generation fails**

Verify that FFmpeg is installed, the generated PNG files exist, and the destination directory is writable.
